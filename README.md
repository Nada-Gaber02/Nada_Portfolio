# Nada Gaber Portfolio — React + Tailwind CSS

A responsive personal portfolio starter built with React, Vite, Tailwind CSS v4, and Lucide icons.

## Requirements
- Node.js 20.19+ (or a compatible current Node.js version)
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL Vite prints in the terminal.

## Build for production
```bash
npm run build
npm run preview
```

## Personalize before publishing
1. In `src/App.jsx`, replace `YOUR_EMAIL@example.com` with your real email.
2. Update the LinkedIn URL.
3. Check project links and descriptions; replace placeholders with your real repository/demo links.
4. Replace the experience descriptions with the exact details from your CV.
5. Edit the skills and project arrays at the top of `src/App.jsx` as needed.

## Styling
- `src/index.css` contains the custom design system, responsive layout, and Tailwind import.
- `src/App.jsx` contains the page sections and content.
- `vite.config.js` configures React and Tailwind CSS v4.
